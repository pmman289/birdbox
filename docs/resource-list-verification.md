# 资源管理列表改造与验收

## 行为

11 类资源使用统一的筛选、结果、列表与分页布局。关键词匹配名称、标识及该类资源的地址、前缀、接口、路由表等字段；多个关键词同时匹配。按资源类型展示节点范围、配置状态、连接状态、地址族、Define/Function 类型、Static 路由来源或 RPKI 来源筛选。选择具体节点时包含适用的全局资源，也可单独查看全局资源。

默认每页 20 条，可选择 10/20/50/100 条，提供页码、上一页/下一页、跳页和结果范围。每个页签保留独立筛选、排序、页码与分页大小；修改条件或分页大小回到第一页，刷新与编辑保留当前视图。删除导致当前页不存在时回退到有效页；新增资源若匹配条件则打开其所在页，不匹配时提示用户重置筛选。

名称排序只影响列表视图。Define 和 Function 显示全局声明序号，分页不会改变声明顺序；无筛选且按声明顺序查看时可跨页调整。筛选或名称排序期间禁用上移/下移，避免意外移动到当前不可见的相邻声明。

节点批量选择区分本页 Agent 和全部筛选结果，跨页/跨筛选保留选择，显示不在本页的已选数量。删除节点或变更管理方式后清理失效选择。原有升级确认流程保留。

列表有刷新、首次加载、空库存及无匹配结果状态。移动端筛选采用双列、搜索占满整行，表格独立滚动并固定操作列；分页控件换行。长标识省略显示，悬停可查看完整内容。
