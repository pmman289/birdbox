# eBGP / iBGP / OSPF 工作区体验回归（2026-10-19）

本轮只调整前端组织和交互，不修改库存迁移、协议默认策略、配置生成语法或自动下发规则。打开页面、选择配置对象和切换端点均不得创建或启用任何库存协议；预检继续由服务端生成和检查完整候选配置，远端变更继续要求确认。

## 用户流程

- eBGP：基础连接 → IPv4 / IPv6 独立策略 → 预检与应用。步骤入口可直接定位，保留节点与远端上下文、草稿状态和影响节点。操作区固定在可见区域；重新加载和删除与主操作分开。自动预检使用非阻塞提示，等待时仍可点击和修改其它字段，应用绑定当前草稿版本。
- iBGP：域与节点 → 选择连接 → 编辑当前端点 → 预检所有受影响节点 → 确认应用。默认显示一端，切换保留另一端草稿；需要对照时选择“同时查看双端”。策略、候选配置默认折叠。桌面默认左侧拓扑、右侧端点，窄屏单列。选择没有邻接的节点时清除旧连接选择，防止改错对象。
- OSPF：域摘要、节点、链路、Area 各自展示对应内容；链路和 Area 编辑时不混入节点表单或其它节点的运行态。节点配置先于节点切换列表；Import / Export 与 Area 高级项默认折叠。手机选择对象后定位到编辑器，并提供返回拓扑入口。短桌面窗口允许编辑区缩小并独立滚动；关闭滚动锚定，展开高级项不再跳到列表末尾。
