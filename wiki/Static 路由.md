# Static 路由

Static 是节点级资源，独立于 BGP 会话。每个实例对应 IPv4 或 IPv6；双栈分别创建两个实例。

## 添加路由

进入“资源管理 → Static → 添加 Static”，填写名称和所属节点。新建默认使用当前节点。

可以同时使用以下路由来源：

- **直接添加路由**：点击“添加路由”，填写完整目标 CIDR，选择下一跳、递归、丢弃、不可达或禁止访问。
- **从 CIDR Define 批量生成**：选择当前节点适用、地址族匹配的 Define。生成的条目与手动路由显示在同一列表，共用下一跳、ECMP、递归、接口、BFD、启停和路由属性控件。网段只读，转发设置可逐条覆盖。
- **自定义 Static 指令**：位于协议高级设置，只填写协议块内部内容。

取消或切换 Define 关联不会清除直接添加的路由；同一次编辑中重新选择原 Define 会恢复其条目草稿。Define 是引用关系；后续修改 Define 会影响所有引用它的 Static。`/24+`、`{24,32}` 等前缀集合表达式不会被展开成静态路由，只有完整 CIDR 会生成路由。

## 转发方式

| 方式 | 设置 |
| --- | --- |
| 下一跳 | 指定同地址族 IP，可选出口接口 |
| 接口路由 | 下一跳地址留空，填写接口名 |
| ECMP | 添加多个独立下一跳，分别设置接口、权重、BFD |
| 递归 | 指定递归下一跳 IP，可在协议高级设置中选择 IGP 查询表 |
| blackhole | 静默丢弃 |
| unreachable | 返回不可达，等价于 BIRD 的 reject |
| prohibit | 返回禁止访问 |

IPv6 链路本地下一跳必须指定接口，也可输入 `fe80::1%eth0`；服务器会拆分并规范化。权重范围 1–256。Onlink 必须同时指定地址和接口。同一个下一跳不能同时启用 BFD 和 Onlink。

BFD 启用时，Birdbox 自动生成配套 BFD 实例；会话建立后才发布对应下一跳，失效时撤销。接口型下一跳不能单独启用 BFD。协议的 `check link` 会在出口接口链路断开时撤路，实际支持受平台和驱动影响。

直接添加支持同一前缀的多条独立路由，包括不同 Static 实例中的主备路由；使用 Preference 或 Metric 区分。直接路由使用独立 ID 保存。每个关联 Define 的完整 CIDR 生成一条路由，需要主备时可额外直接添加同前缀路由。

“批量操作”以当前条目为模板，可统一所有条目的转发配置、复制路由属性或清空属性。批量转发设置保留各条目启停状态，并成为 Define 后续新增网段的默认转发配置；逐条编辑只影响当前条目，属性不会自动继承到未来网段。

## 路由表与属性

“写入 BIRD 路由表”默认 IPv4 为 `master4`、IPv6 为 `master6`，可引用已有表或由 Birdbox 创建。该名称与 Kernel 的 Linux 内核表编号不同。

Static 与 Pipe 共享管理表声明，按节点和表名去重。同名管理表必须属于同一地址族。停用资源保留表声明；删除最后一个管理引用时，如果其它配置仍依赖该表，完整预检会拒绝删除并保留原状态。

路由高级设置支持启停单条路由、Preference、IGP Metric、BGP Local Pref/MED/Origin、标准和 Large Community、AS prepend，以及自定义 per-route 代码。快捷操作按顺序执行，随后执行自定义代码。

Import 控制静态路由进入 BIRD 路由表，默认允许，支持 all/none、Function 组合和 Filter。静态路由是否向 BGP/OSPF 发布由对应协议的策略决定。Static 的 Export 默认 none，通常保持默认。

## 预检与应用

“预检并查看变更”在服务端生成规范化候选配置，返回完整节点配置、与库存配置的差异和实际节点预检结果，不保存库存或更改活动配置。停用资源会额外检查启用后的合法性。

点击“预检并查看变更”先预检并打开变更；确认后点击“保存并应用”。应用会重新执行完整预检，使用已确认候选的 ID 和库存 revision，沿用部署锁、CAS、journal 与失败回滚。修改草稿会使旧预检失效；库存冲突或失败保留编辑内容，需要重新预检后提交。直接调用保存 API 仍会执行完整预检。

关闭有修改的编辑器需要确认。应用期间字段锁定，操作按钮固定在可见区域。编辑已有 Static 时不能直接切换所属节点。

## 运行态与路由

在 Static 列表中点击“运行态”，查看协议实际状态、最近检查时间、导入路由数量和原始详情，支持跳转编辑。

路由详情按已保存的节点、表名和协议名查询，可选目标 IP；最多显示 200 条并提示截断。请求失败与无路由分别显示，过期响应不会覆盖当前查询。停用配置显示停用状态和空路由。

该页面反映 BIRD 中的路由，不表示已经写入操作系统内核。协议运行但缺少预期路由时，检查下一跳、BFD、链路状态及 Import 策略；未选中的备用路由也可能仍在 BIRD 表中。

## 自定义指令

只填写 Static 块内部语句，不包含 `protocol static` 和外层花括号，例如：

```bird
route 203.0.113.0/24 via 192.0.2.1;
```

Birdbox 检查 Define、Function、Filter 的作用域和引用依赖。自定义路由不进入结构化条目编辑，复杂语法仍由节点实际 BIRD 预检确认。

当前结构化管理针对 IPv4/IPv6 单播，不提供 MPLS、VPN、FlowSpec 等地址族编辑。
